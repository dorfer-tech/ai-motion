# AI Motion
Shared tools from the AI Motion community. Post MCP clients, servers, agents and other tools you want fellow members to use, each in its own folder with a README on setup. Open a pull request to add yours, and share questions or demos in the AI Motion WhatsApp community.

## How to contribute

1. Add a folder named after your tool (for example `my-mcp-server/`).
2. Put a `README.md` in that folder with what it does, how to install it, and how to run it.
3. Open a pull request.

Each folder can carry its own license file. The repo default is MIT.

## Repo structure

```
ai-motion/
├── README.md
├── LICENSE                 # MIT by default
└── your-tool-name/
    ├── README.md           # setup and usage
    ├── LICENSE             # optional; overrides the repo default for this folder
    └── ...                 # your code
```
